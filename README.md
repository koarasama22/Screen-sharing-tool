# 画面共有ツール（同意ベース）の使い方

このツールは、共有される側（送信側）が自分の意思で開始・停止できる画面共有です。
サーバーの構築なしで、2つのHTMLファイルをブラウザで開くだけで動きます。

## 使い方

1. **送信側（共有される側のChromebook）**
   - `broadcaster.html` を Chrome で開きます。
   - 表示された「接続コード」を、見る側の人に伝えます（電話・チャットなどで）。
   - 「共有を開始する」を押し、共有したい画面/ウィンドウ/タブを選びます。
   - 止めたいときは「共有を停止する」、またはChromeが表示する共有バーの
     「共有を停止」ボタンを押せば、いつでも即座に止まります。

2. **閲覧側（見る側のChromebook）**
   - `viewer.html` を Chrome で開きます。
   - 送信側から伝えられた「接続コード」を入力し、「接続する」を押します。
   - 相手が共有を開始すると、画面が表示されます。

## 注意点・仕組み

- 通信は WebRTC による**P2P（直接通信）**です。映像データは仲介サーバーを経由しません。
  (最初の接続確立だけ、無料のPeerJSクラウドサービスを使います)
- 送信側がページを閉じる、ブラウザを閉じる、共有停止を押す、のいずれかで
  共有は即座に終了します。バックグラウンドで動き続けることはありません。
- ファイルをそのままダブルクリックで開いても動作しますが、
  インターネット越しに使う場合は両方とも `https://` 経由で開く必要があります
  （ブラウザのセキュリティ制限のため）。GitHub Pages や Netlify などの
  無料静的ホスティングにこの2ファイルを置くと簡単に公開できます。

## ホスティング方法（インターネット経由で使う場合）

例：GitHub Pagesを使う場合
1. GitHubでリポジトリを作成し、この2つのHTMLファイルをアップロード
2. リポジトリの Settings → Pages で公開を有効化
3. 発行されたURL（例: `https://ユーザー名.github.io/リポジトリ名/broadcaster.html`）に
   両方のChromebookからアクセス

同一Wi-Fi内で使うだけなら、簡易サーバー（例: `python3 -m http.server`）でも構いません。
